Ofte stillede spørgsmål

Hvordan inviterer jeg mine medejere?

Husets admin går til Huset → Deling → Lav invitationslink og sender linket. Medejerne skal have appen og være logget ind på iCloud.

Hvad er forskellen på ejer og medlem?

Ejere deler husets udgifter og kan se dem. Medlemmer kan booke, se husbogen, løse opgaver og skrive beskeder. Admin bestemmer, hvem der er hvad.

Kan jeg bruge euro?

Ja. Hver udgift kan være i kroner eller euro, og saldoen vises i den valuta, I vælger under Indstillinger.

Hvor gemmes mine data?

I din egen iCloud. Vi har ingen server og kan ikke se jeres data. Læs mere i privatlivspolitikken.

Hvordan sletter jeg mine data?

I appen: Huset → Indstillinger → Dine data.
